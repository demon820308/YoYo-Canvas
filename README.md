# YoYo-Canvas

一款跑在 Muse 全栈空间里的 AI 无限画布：把文本、图片、视频、音频节点摆在同一张画布上连线组装，用平台自身的生成能力出图、出视频、出音频，成品落在画布节点与项目目录里。

## 功能概览

- 无限画布：拖拽、缩放、框选、右键/双击新建菜单、MiniMap、节点编号（每项目独立计数、删号不复用）
- 节点类型：文本、图片、视频、音频、生成配置、分组、便签，以及四个工具节点（视频抽帧、提取音频、视频配乐、提示词逆推）
- 图片生成八档比例（16:9 / 9:16 / 1:1 / 3:2 / 2:3 / 4:3 / 3:4 / 21:9），每档对应确切像素，节点尺寸只记实测值
- 双生成通道：基础三档比例且无参考媒体时直出同步出图，其余走任务队列（每轮最多 3 个并行）；队列抽屉带「记录」页签，生成历史持久保存，节点删了记录还在
- 资产库按项目隔离，提示词库全局共用

## 仓库结构

```
client/     前端源码（React 19 + TypeScript）
server/     服务端动作源码
drizzle/    数据库迁移（0001–0014）
app.db      空数据库（表结构就绪，无项目数据）
blobs/      媒体 blob 存储目录（本仓库为空）
DATA-PLAN.md / ENGINEERING.md / FILE-ORGANIZATION.md / AGENTS.md  工程文档
Deploy-YoYo-Canvas.md  跨 Muse 部署提示词
icon.webp   空间图标
```

## 部署到另一个 Muse

本仓库是干净版源码包：不含任何项目数据与历史媒体。部署方法见 [Deploy-YoYo-Canvas.md](Deploy-YoYo-Canvas.md)——把本仓库下载为 zip 上传到目标 Muse，在对话里发文档中的提示词整段，创建空间时 slug 定为 `yoyo-canvas`、显示名定为 `YoYo-Canvas`。
